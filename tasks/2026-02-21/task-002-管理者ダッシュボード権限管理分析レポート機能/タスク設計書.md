# タスク設計書：管理者ダッシュボード・権限管理・分析レポート機能

## タスクID
task-002

## タスクタイトル
管理者ダッシュボード・権限管理・分析レポート機能

## ユーザーニーズ

### 背景
AIキャリア診断サービスを運営する管理者が、以下を実現したい：

1. **運営状況の把握**: 診断利用数、ユーザー動向を一目で把握したい
2. **ユーザー管理**: 不正利用の抑制、ロール（権限）の付与・変更を行いたい
3. **分析・改善**: 診断結果の傾向、人気キャリアパスを分析しサービス改善に活かしたい
4. **障害対応**: エラー発生を早期に検知し、迅速に対応したい

### 解決すべき課題
- 管理者専用の安全な管理画面
- 診断データの可視化とエクスポート
- ユーザー権限の一元管理（admin/user）
- エラー監視と通知体制

## 仕様要件

### 機能要件

#### 1. 管理者専用ダッシュボード（/admin）
- **URL**: `/admin`
- **認証**: adminロール必須
- **表示内容**: 本日の診断数、総診断数、アクティブユーザー数、最近の診断結果一覧（5件）、システムステータス、クイックアクションボタン

#### 2. 診断分析レポート（/admin/analytics）
- **URL**: `/admin/analytics`
- **機能**: 診断数の日別・週別・月別グラフ、人気キャリアパスTOP10、診断完了率、CSVエクスポート

#### 3. ユーザー管理（/admin/users）
- **URL**: `/admin/users`
- **機能**: ユーザー一覧（ページネーション）、検索・フィルタ、ロール変更、ユーザー詳細

#### 4. エラーログ監視（/admin/errors）
- **URL**: `/admin/errors`
- **機能**: Sentry連携、エラーログ一覧表示

### 技術要件
- NextAuth.js v5のセッションにroleを追加
- usersコレクションにrole: 'admin'|'user' を追加
- ミドルウェアで/adminパスを保護（adminロール必須）
- MUI DataGrid, Card, Chip, Tab, Avatar使用
- rechartsでグラフ描画
- @sentry/nextjsでエラー監視

## 処理手順設計

### Phase 1: 基盤構築
1. Userのrole拡張（lib/getUserId, usersコレクション）
2. NextAuth callbacksでsession.user.roleを付与
3. ミドルウェアで/admin保護（adminロール必須）

### Phase 2: API実装
- GET /api/admin/stats - ダッシュボード統計
- GET/PATCH /api/admin/users - ユーザー一覧・ロール変更
- GET /api/admin/analytics - 分析データ
- GET /api/admin/errors - エラーログ

### Phase 3: 画面実装
- /admin レイアウト（サイドバー・タブ）
- /admin ダッシュボード
- /admin/analytics（recharts）
- /admin/users（DataGrid）
- /admin/errors
