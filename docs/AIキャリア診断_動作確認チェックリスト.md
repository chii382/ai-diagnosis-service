## 9. API エンドポイント

### POST /api/diagnosis

- [ ] **9-1** 正しい `answers` を送信すると 200 と診断結果が返る
- [ ] **9-2** `answers` が不正な場合 400 が返る
- [ ] **9-3** 未認証で 401 が返る
- [ ] **9-4** `ANTHROPIC_API_KEY` 未設定時 500 が返る

### GET /api/diagnosis

- [ ] **9-5** 認証済みで 200 と `items` 配列が返る
- [ ] **9-6** 未認証で 401 が返る

### GET /api/diagnosis/[id]

- [ ] **9-7** 自分の診断の id で 200 と詳細が返る
- [ ] **9-8** 存在しない id で 404 が返る
- [ ] **9-9** 未認証で 401 が返る

### PUT /api/diagnosis/[id]

- [ ] **9-10** 正しい `result` / `careerRoadmap` で 200 と更新後データが返る
- [ ] **9-11** 存在しない id で 404 が返る
- [ ] **9-12** 未認証で 401 が返る

### DELETE /api/diagnosis/[id]

- [ ] **9-13** 自分の診断の id で 200 と `{ success: true }` が返る
- [ ] **9-14** 存在しない id で 404 が返る
- [ ] **9-15** 未認証で 401 が返る
