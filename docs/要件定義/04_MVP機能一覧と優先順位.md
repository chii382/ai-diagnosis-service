# MVP機能一覧と優先順位

## MVPの定義
**MVP（Minimum Viable Product）**：ユーザーがサービスを理解し、診断を開始できる最小限の機能を持つLP

---

## 機能一覧

### 1. LP（ランディングページ）機能

#### 1.1 ヒーローセクション（優先度：最高）
- **機能ID**：FUNC-001
- **機能名**：ヒーローセクション表示
- **説明**：ページ上部にキャッチコピー、サブコピー、CTAボタンを表示
- **必須要素**：
  - キャッチコピー：「5問でわかる、あなたのキャリア」
  - サブコピー：サービスの価値提案（例：「AIがあなたに最適なキャリアロードマップを作成します」）
  - CTAボタン：「診断を始める」ボタン（診断ページへのリンク）
- **優先度**：最高
- **工数見積**：4時間

#### 1.2 サービス特徴セクション（優先度：最高）
- **機能ID**：FUNC-002
- **機能名**：サービス特徴3つの表示
- **説明**：サービスの特徴を3つに分けて説明
- **必須要素**：
  - 特徴1：簡単さ（5問だけで完了）
  - 特徴2：AIによる適性診断
  - 特徴3：具体的なロードマップ
- **優先度**：最高
- **工数見積**：6時間

#### 1.3 診断の流れセクション（優先度：高）
- **機能ID**：FUNC-003
- **機能名**：診断の流れ（3ステップ）表示
- **説明**：診断がどのように進むかを3ステップで説明
- **必須要素**：
  - ステップ1：質問に回答（5問）
  - ステップ2：AIが分析
  - ステップ3：ロードマップを取得
- **優先度**：高
- **工数見積**：4時間

#### 1.4 ページ下部CTA（優先度：最高）
- **機能ID**：FUNC-004
- **機能名**：ページ下部CTAボタン表示
- **説明**：ページ下部に再度「診断を始める」CTAボタンを配置
- **必須要素**：
  - CTAボタン：「診断を始める」ボタン
- **優先度**：最高
- **工数見積**：2時間

#### 1.5 フッター（優先度：中）
- **機能ID**：FUNC-005
- **機能名**：フッター表示
- **説明**：ページ下部にフッターを表示
- **必須要素**：
  - コピーライト表示
  - サービス名
  - （将来的に）プライバシーポリシー、利用規約へのリンク
- **優先度**：中
- **工数見積**：2時間

### 2. UI/UX機能

#### 2.1 レスポンシブデザイン（優先度：最高）
- **機能ID**：FUNC-006
- **機能名**：レスポンシブデザイン対応
- **説明**：PC、タブレット、スマートフォンで適切に表示される
- **必須要素**：
  - ブレークポイント：スマートフォン（〜768px）、タブレット（769px〜1024px）、PC（1025px〜）
  - モバイルファーストデザイン
- **優先度**：最高
- **工数見積**：8時間

#### 2.2 スクロールアニメーション（優先度：低）
- **機能ID**：FUNC-007
- **機能名**：スクロール時のアニメーション
- **説明**：スクロール時に要素がフェードインするなどのアニメーション
- **優先度**：低
- **工数見積**：4時間
- **備考**：時間があれば実装

#### 2.3 スムーススクロール（優先度：低）
- **機能ID**：FUNC-008
- **機能名**：アンカーリンクのスムーススクロール
- **説明**：ページ内リンクをクリックした際にスムーズにスクロール
- **優先度**：低
- **工数見積**：1時間
- **備考**：時間があれば実装

## 技術的な実装詳細

### 使用技術
- **フレームワーク**：Next.js 15（App Router）
- **UIライブラリ**：Material-UI (MUI)
- **スタイリング**：MUIのテーマシステム
- **言語**：TypeScript

### コンポーネント構成（想定）
```
app/
  page.tsx (LPのメインページ)
  layout.tsx (ルートレイアウト)
components/
  HeroSection.tsx (ヒーローセクション)
  FeaturesSection.tsx (サービス特徴)
  FlowSection.tsx (診断の流れ)
  CTAButton.tsx (CTAボタン)
  Footer.tsx (フッター)
  Header.tsx (ヘッダー)
```

### MUIテーマ設定
- カラーパレット：キャリア・成長をイメージした色（例：ブルー、グリーン）
- タイポグラフィ：読みやすいフォントサイズと行間
- スペーシング：適切な余白で読みやすさを確保

## 非機能要件

### パフォーマンス要件
- **ページ読み込み時間**：3秒以内
- **Lighthouseスコア**：90以上（Performance）
- **First Contentful Paint (FCP)**：1.8秒以内
- **Largest Contentful Paint (LCP)**：2.5秒以内

### アクセシビリティ要件
- **WCAG 2.1**：レベルAA準拠を目指す
- **キーボード操作**：すべての機能がキーボードで操作可能
- **スクリーンリーダー**：適切なaria-label、alt属性を設定

### ブラウザ対応
- **Chrome**：最新版と1つ前のバージョン
- **Safari**：最新版と1つ前のバージョン
- **Firefox**：最新版と1つ前のバージョン
- **Edge**：最新版と1つ前のバージョン

### SEO要件
- **メタタグ**：適切なtitle、description、OGPタグを設定
- **構造化データ**：可能であればJSON-LDを実装
- **セマンティックHTML**：適切なHTMLタグを使用

## 成功基準

### Week1終了時の目標
1. **機能完成度**：Phase 1とPhase 2の機能が実装されている
2. **デザイン完成度**：MUIを使用した統一感のあるデザイン
3. **レスポンシブ対応**：PC、タブレット、スマートフォンで適切に表示される
4. **パフォーマンス**：Lighthouseスコア80以上
5. **アクセシビリティ**：基本的なアクセシビリティ要件を満たす

### 測定指標
- **実装完了率**：Phase 1 + Phase 2の機能実装率100%
- **デザイン品質**：デザインレビューでの承認
- **パフォーマンススコア**：Lighthouseでの測定結果
- **ブラウザ互換性**：主要ブラウザでの動作確認
