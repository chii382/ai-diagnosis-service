## 2. 診断フォーム（/diagnosis）

- [ ] **2-1** ページが表示される（ヘッダー・ナビゲーション含む）
- [ ] **2-2** タイトル「AIキャリア診断」が表示される
- [ ] **2-3** 5問の質問がアコーディオン形式で表示される
  - [ ] Q1: 現在のキャリア状況は？
  - [ ] Q2: 得意な分野やスキルは何ですか？
  - [ ] Q3: 働き方の希望は？
  - [ ] Q4: キャリアで最も重視するものは？
  - [ ] Q5: 目標を達成したい時期は？
- [ ] **2-4** 全問未入力時、「診断を実行」ボタンが無効（disabled）
- [ ] **2-5** 全問入力後、「診断を実行」ボタンが有効
- [ ] **2-6** 「診断履歴を見る」「ダッシュボードに戻る」リンクが表示される

## 3. AI分析の実行・結果の保存

- [ ] **3-1** 5問すべてに回答して「診断を実行」をクリックする
- [ ] **3-2** ローディング表示（「診断中...」等）が表示される
- [ ] **3-3** API呼び出しが成功し、エラーが出ない
- [ ] **3-4** 診断完了後、`/diagnosis/[id]`（診断結果詳細）へ自動リダイレクトされる
- [ ] **3-5** 診断結果が画面に表示される

## 4. 診断結果詳細（/diagnosis/[id]）
