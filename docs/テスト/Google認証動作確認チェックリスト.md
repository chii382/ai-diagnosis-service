## 9. セッションの維持

### 確認手順
1. ログイン後、ブラウザを閉じずに別のタブを開く
2. 時間を置いてから、再度保護されたページにアクセス

### 確認項目
- [ ] ログイン後、ブラウザを閉じずに別のタブで `/dashboard` にアクセスすると、ログイン状態が維持される
- [ ] ページをリロードしても、ログイン状態が維持される
- [ ] 一定時間経過後も、ログイン状態が維持される（セッションの有効期限内）
- [ ] セッションが無効化されると、自動的にログインページにリダイレクトされる
- [ ] 複数のタブで同じセッションが共有される
- [ ] エラーが発生しない（コンソールエラーなし）

### 期待される結果
- セッションが適切に維持され、ログイン状態が保持されること

### 備考
- **注意**: セッションの有効期限はNextAuth.jsの設定に依存します。JWT方式を使用している場合、デフォルトでは30日間有効です。
