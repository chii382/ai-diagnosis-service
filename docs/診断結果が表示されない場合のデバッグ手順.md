# 診断結果が表示されない場合のデバッグ手順

## 想定される原因

1. **診断処理でエラーが発生している** - AI API呼び出しやDB保存時に失敗
2. **診断結果がDBに登録されていない** - 保存処理が失敗している
3. **表示されていないだけ** - DBには保存されているが、画面や取得処理の問題

---

## 手順1: デバッグAPIで確認（推奨）

開発サーバー起動中に、ブラウザで以下にアクセスしてください（ログイン済みの状態で）：

```
http://localhost:3000/api/diagnosis/debug
```

**確認ポイント：**

| 項目 | 意味 |
|------|------|
| `session.exists` | true = ログイン済み、false = 未ログイン |
| `userId` | 取得できていれば表示。null = ユーザーがDBにない |
| `diagnosisCount` | あなたの診断件数。0 = まだ1件も保存されていない |
| `latestInDb` | DB内の最新診断（全体）。`userId` と一致するか確認 |
| `userIdMismatch` | 診断はあるが userId が異なる場合に true |

---

## 手順2: ターミナル（サーバーログ）を確認

`npm run dev` を実行したターミナルで、診断実行時に以下のログが出ます：

### POST（診断実行）時のログ例

```
[getUserId] found user: { email: 'xxx...', userId: '...' }
[Diagnosis POST] 1. auth start
[Diagnosis POST] 2. auth done { hasSession: true, email: 'xxx...' }
[Diagnosis POST] 3. userId ok { userId: '...' }
[Diagnosis POST] 4. answers ok { keys: ['q1','q2','q3','q4','q5'] }
[Diagnosis POST] 6. calling Anthropic API
[Diagnosis POST] 7. Anthropic API response received
[Diagnosis POST] 8. connecting DB and saving
[Diagnosis POST] 9. diagnosis saved { id: '...' }
```

**どこで止まるかで原因を特定：**

- `3. userId missing` → セッションまたはユーザー取得失敗
- `6. calling...` の後、エラー → Anthropic API のエラー（APIキー、ネットワーク等）
- `8. connecting...` の後、エラー → MongoDB接続または保存エラー

### GET（診断詳細取得）時のログ例

```
[Diagnosis GET id] 1. params { id: '...' }
[Diagnosis GET id] 2. auth { hasSession: true }
[Diagnosis GET id] 3. userId ok { userId: '...' }
[Diagnosis GET id] 5. not found { docExists: true, docUserId: 'A', queryUserId: 'B' }
```

- `5. not found` の `docExists: true` かつ `userIdMismatch: true` → **userId の不一致**（診断はDBにあるが、別ユーザーとして作成されている）

---

## 手順3: ブラウザの開発者ツール

### Networkタブ

1. F12 で開発者ツールを開く
2. 「Network」タブを選択
3. 診断を実行

**確認するリクエスト：**

| リクエスト | 確認ポイント |
|-----------|--------------|
| `POST /api/diagnosis` | Status 200 なら成功。500 なら Response タブで `error` を確認 |
| `GET /api/diagnosis/xxxxx` | Status 200 なら成功。404 なら「診断結果が見つかりません」 |

### Consoleタブ

開発環境では以下のログが出ます：

- `[診断] POST response:` - 診断実行のレスポンス
- `[診断] redirecting to:` - リダイレクト先
- `[診断詳細] GET response:` - 詳細取得のレスポンス

---

## よくある原因と対処

### 1. userId の不一致

**症状：** 診断実行は成功するが、詳細ページで 404

**原因：** POST 時の `userId` と GET 時の `userId` が異なる。  
（例：POST で新規ユーザー作成 → GET で別DB/別コレクションから検索）

**対処：** `lib/getUserId.ts` と MongoDB の接続先（DB名・コレクション）を確認。  
`MONGODB_URI` のデータベース名が統一されているか確認。

### 2. Anthropic API エラー

**症状：** 診断実行で 500 エラー

**対処：**  
- `.env.local` に `ANTHROPIC_API_KEY` が正しく設定されているか確認  
- ターミナルに表示されるエラーメッセージを確認

### 3. セッション切れ

**症状：** 401 Unauthorized

**対処：** ログアウト後に再ログインしてから再度診断を実行。

---

## ログの無効化

本番環境では、`NODE_ENV=production` のため上記のデバッグログは出力されません。
