# Googleログイン画面のアプリ名変更手順

「Googleでログイン」ボタンをクリックした後の画面に表示される「**[アプリ名]に移動**」の文言を「**AI CAREER COMPASSに移動**」に変更する手順です。

## 変更方法

この文言は **Google Cloud Console** の OAuth 同意画面で設定されたアプリ名が表示されます。コードでは変更できないため、以下の手順で Google Cloud Console から変更してください。

### 1. Google Cloud Console にアクセス

1. [Google Cloud Console](https://console.cloud.google.com/) にログイン
2. 本プロジェクトの Google Cloud プロジェクトを選択

### 2. OAuth 同意画面を編集

1. 左メニューから「**APIとサービス**」→「**OAuth 同意画面**」に移動
2. 編集対象のアプリ（タイプ: 外部 または 内部）を選択し、「**編集**」をクリック
3. **アプリ情報** の最初のステップで、以下の項目を変更：
   - **アプリ名**: `AI CAREER COMPASS` に変更
   - （必要に応じて）ユーザーサポートメールなどの他項目も確認
4. 「**保存して次へ**」をクリックして進め、最後に「**保存**」で完了

### 3. 反映の確認

- 変更は数分以内に反映される場合が多いです
- ブラウザのキャッシュをクリアするか、シークレットウィンドウで再度「Googleでログイン」を試してください
- 「**AI CAREER COMPASSに移動**」と表示されれば完了です

## 注意事項

- アプリが「テスト」モードの場合、許可されたテストユーザーのみログインできます
- 本番公開時は OAuth 同意画面の「アプリの公開」申請が必要になる場合があります
