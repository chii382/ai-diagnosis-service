## セクション詳細

### 1. ヘッダー

| 項目 | 内容 |
|------|------|
| 左側 | サービスロゴ（テキストロゴ） |
| 右側 | 「診断を始める」ボタン（小） |
| 背景 | 透明または白（スクロール時に固定） |
| レスポンシブ | モバイルではハンバーガーメニュー不要（シンプル構成のため） |

---

### 2. ヒーローセクション

| 項目 | 内容 |
|------|------|
| キャッチコピー | 「5問でわかる、あなたのキャリア」 |
| サブコピー | 「AIがあなたに最適なキャリアロードマップを提案します」 |
| CTAボタン | 「無料で診断を始める」 |
| 背景 | グラデーション（淡いブルー〜パープル系）または抽象的なイラスト |
| アニメーション | フェードイン、軽いパララックス効果（オプション） |

#### デザイン仕様
- **キャッチコピー**: `h1`, フォントサイズ 48px (PC) / 32px (モバイル), font-weight: 700
- **サブコピー**: `p`, フォントサイズ 20px (PC) / 16px (モバイル), color: gray[600]
- **CTAボタン**: 大きめ、角丸、グラデーション背景、ホバーで明るく
- **セクション高さ**: 100vh または min-height: 600px

---

### 3. 特徴セクション

3つのカードを横並び（モバイルでは縦並び）で表示

| カード | アイコン | タイトル | 説明文 |
|--------|----------|----------|--------|
| 1 | ⏱️ (Timer) | たった5問・3分で完了 | 忙しいあなたでも、スキマ時間でサクッと診断できます |
| 2 | 🧠 (Psychology) | AIが深く分析 | 最新のAI技術があなたの回答を多角的に分析します |
| 3 | 🎯 (Target) | パーソナライズされた提案 | あなただけのキャリアロードマップを作成します |

#### デザイン仕様
- **カード**: MUI Card コンポーネント、影あり、角丸
- **アイコン**: MUI Icons、サイズ 48px、プライマリカラー
- **タイトル**: `h3`, font-weight: 600
- **説明文**: `p`, color: gray[600]
- **レイアウト**: Grid (3列 → 1列 on mobile)
- **セクション背景**: 白またはライトグレー

---

### 4. ステップセクション

診断の流れを3ステップで視覚的に表示

| ステップ | 番号 | タイトル | 説明 |
|----------|------|----------|------|
| Step 1 | 01 | 質問に回答 | 5つの簡単な質問に答えるだけ |
| Step 2 | 02 | AI分析 | AIがあなたの回答を分析 |
| Step 3 | 03 | 結果表示 | あなた専用のロードマップを表示 |

#### デザイン仕様
- **番号**: 大きな円形バッジ、プライマリカラー背景
- **矢印/コネクター**: ステップ間を繋ぐ点線または矢印
- **レイアウト**: 横並び（PC）→ 縦並び（モバイル）
- **セクション背景**: 淡いグラデーションまたは白

---

### 5. CTAセクション

ページ下部でもう一度行動を促す

| 項目 | 内容 |
|------|------|
| 見出し | 「今すぐキャリア診断を始めましょう」 |
| サブ見出し | 「完全無料・登録不要で診断できます」 |
| CTAボタン | 「無料で診断を始める」 |
| 背景 | グラデーション（ヒーローと同系色）またはプライマリカラー |

#### デザイン仕様
- **見出し**: `h2`, font-weight: 700, 白文字（背景が濃い場合）
- **CTAボタン**: 白背景にプライマリカラーテキスト（背景が濃い場合）
- **パディング**: 上下 80px

---

│   ├── Footer.tsx              # フッター

    └── ThemeProvider.tsx       # テーマプロバイダー

## アクセシビリティ要件

- すべての画像に `alt` 属性を設定
- CTAボタンに適切な `aria-label` を設定
- 色のコントラスト比 WCAG AA 準拠
- キーボードナビゲーション対応
- フォーカス表示の確保
