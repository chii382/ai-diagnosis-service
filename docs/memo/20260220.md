## 1. 市場マッチング機能の実装

設計書（`docs/matching/市場マッチング設計書.md`）に基づき、診断分析レポートに市場マッチング機能を追加。

### 1.1 市場データ取得API

- **パス**: `/api/admin/analytics/market`
- **メソッド**: POST
- **リクエスト**: `{ diagnosisVocab: { industries: string[], jobTypes: string[] } }`
- **処理**: Anthropic API により日本の求人市場の推定需要分布を取得
- **レスポンス**: 業種・職種・年代の需要割合（％）をJSONで返却

### 1.2 診断分析画面の改修（`app/admin/analytics/page.tsx`）

- **診断トレンド**: 診断数推移グラフ＋サマリー（総診断数・診断完了率）
- **診断結果（向いている業種・職種）**: `aptitudeScores` から集計したTOP10の horizontal bar chart
- **ユーザー属性（プロフィール集計）**: 年代別・現状の職種別・現状の業種別
- **市場マッチング**:
  - マッチングサマリー（業種・職種・年代・全体のマッチ度％）
  - 業種・職種の比較グラフ（診断結果 vs 市場需要）
  - ギャップ分析（市場需要高・診断供給低 / 診断高・市場需要低）

### 1.3 セクション表示順

1. 診断トレンド  
2. 診断結果（向いている業種・職種）  
3. ユーザー属性（プロフィール集計：現状の職種・業種）  
4. 市場マッチング（診断結果 vs 市場需要）

## 2. 診断分析APIの変更（`app/api/admin/analytics/route.ts`）

### 2.1 データソースの変更

| 項目 | 変更前 | 変更後 |
|------|--------|--------|
| 年代・職種・業種 | 診断 answers（q3, q4等） | ユーザープロフィール（users コレクションの ageGroup, jobType, industry） |
| 向いている業種・職種 | suitableJobsAnalysis のテキスト解析 | aptitudeScores.業種 / aptitudeScores.職種 |

### 2.2 レスポンス形式

- `byAgeGroup`, `byJobTypeProfile`, `byIndustryProfile`: プロフィール集計
- `bySuitableIndustry`, `bySuitableJobType`: 診断結果集計
- `topCareers` を廃止
